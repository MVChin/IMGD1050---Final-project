# IMGD1050---Final-project
Final project for submission
This is a p5.js project that is meant to reinforce basic 3D solid visualization that is appropriate for High School Geometry.  Students will be able to select the type of solid and set various dimensions and will be able to not only view a 3D model of the prescribed solid but be able to rotate it to view it any orientation but will also be able to view calculations that determine the solid's volume and surface area.

#Process
Each solid is constructed as a custom shape using vertex() functions.  The linear center of the solid is positioned at the origin so all angle calculations do not require any offset shifting
